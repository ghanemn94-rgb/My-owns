# ADR-0011: Packaging, configuration and the no-outbound-internet runtime rule

- **Status:** Proposed for DG1. **Date:** 2026-09-30. **Author:** solution-architect.
- **Requirements:** REQ-S16-008, REQ-S16-031, REQ-S01-006, REQ-S19-009, REQ-S19-010, REQ-S19-019.

## Decision

1. **Images** (devops-engineer writes them under `deploy/docker/`):
   - `mth-app`: a multi-stage build on `node:24-bookworm-slim`, pinned **by digest** [UNVERIFIED tag].
     - Build stage: `pnpm install --frozen-lockfile` from the committed lockfile, then `pnpm -r build`, then `pnpm deploy --prod`.
     - Runtime stage: non-root user, read-only root filesystem, `NODE_ENV=production`, `AUTH_MODE=oidc`, and no pnpm or build tools.
     - One image, three commands: `api`, `worker`, `migrate`. The SPA `dist/` is copied into the API's static directory.
   - Third-party licence texts and OFL font notices go into `/app/licenses`.
2. **Compose** (`deploy/compose/compose.yaml`), for reproducible install and test only:
   - services: `db` (postgres:18, digest-pinned), `migrate` (one-shot; `depends_on` the healthy db), `api`, `worker`;
   - profile `test-idp`: `keycloak` with the realm import.

   Health checks use `/healthz` and `/readyz`. Evidence and PostgreSQL data use named volumes. Compose is **not** presented as proof of high-availability production readiness (§16).
3. **Configuration** (`@mth/config`):
   - Every setting is an environment variable listed in `ENV_VARS`, and secrets can also be read from `<NAME>_FILE`.
   - A zod loader validates at startup and exits non-zero with a clear message.
   - `.env.example`, generated by devops from the catalogue, contains **no secret values**.
   - No secrets in the repository. The logger redacts credentials. The web bundle receives only `/me` data, never config.
4. **No outbound internet at runtime.**
   - Mandatory runtime services: PostgreSQL and the corporate OIDC IdP. Both run inside company-controlled infrastructure.
   - The application makes **no outbound calls** except to the configured IdP (and later to IT-configured SMTP, connectors or an AI endpoint, all optional and off by default).
   - No telemetry, analytics, CDN, remote fonts or update checks.
   - A P1 smoke test runs the Compose stack with the app network marked `internal: true` (no egress) and checks login (with Keycloak on the same internal network), create and read. Full A18 comes at DG7.
5. **Restricted-network builds:** images can be built from IT's npm mirror (`npm_config_registry`) and base-image mirror. The lockfile's integrity hashes guarantee identical packages. This is documented in the handover (§19 item 7).

## Alternatives

- **Separate web container (nginx).** An extra image with no benefit: same-origin serving from the API simplifies cookies, CSP and CSRF.
- **Kubernetes manifests now.** The IT orchestration target is unknown. Deployment configuration for the real target is a P7 item (REQ-S16-008).
