# T-DG6-BE-RG1: assistant read-time re-check covers every record given to the model (F-DG6-920)

## What to change (read first)

Read F-DG6-920 in `docs/delivery/findings.json`, the round-1 code-security sidecar, and its probe `docs/delivery/test-evidence/DG6/code-security/round-1/repro/zz-sec-r1-assistant-uncited.test.ts` with its log. Reuse that probe as your before-fix reproduction.

1. **Keep the generation context.** When an assistant answer or suggestion is stored, keep the record keys of **every** record item given to the model (not only the model's citations), for example as a stored context list beside the citations. Citations shown to the user stay as they are.

3. **Existing rows.** A migration may add the column; for rows stored before it, fall back to the stored citations and say so in the ADR.
4. **Tests on the real API (integration, with the shipped `http_endpoint` provider and the fake model citing a subset),** each with a before-fix log (fails) and an after-fix log (passes):
   - the F-DG6-920 sequence: answer cites one of two given records; revoke the uncited one; the answer is withheld;
   - the cited-record revoke case still withholds;
   - nothing revoked: the answer is still readable;
   - a suggestion built from an uncited record behaves the same.
5. **Records.** Amend ADR-0059 §5/§9, the OpenAPI description if any field changes, and the data dictionary for any new column.
