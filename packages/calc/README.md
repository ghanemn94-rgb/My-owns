# packages/calc — reserved (P4)

Reserved for `@mth/calc`: the pure, versioned KPI and benefit calculation engine (decimal.js only, no I/O),
used by the API `kpi` module and the worker. It is created in P4 by kpi-benefits-engineer. The directory has
no `package.json` yet, so it is not a workspace member. See ADR-0002.
