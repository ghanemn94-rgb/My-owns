# ADR-0013 — Internationalization: Arabic RTL / English LTR

- Status: Accepted · Date: 2026-09-29
- Requirements: spec §10

## Decision
Lightweight dictionary-based i18n in the web app (`apps/web/src/i18n/messages/{en,ar}/*.json`), locale stored in a
cookie and on the user profile; `<html lang dir>` switches per locale. Components use logical CSS properties only.
Fonts (IBM Plex Sans / IBM Plex Sans Arabic) are bundled via npm (`@fontsource/*`) — no CDN. Technical identifiers and
API fields stay English; enum values are translated through message keys; a bilingual glossary
(`docs/domain-glossary.md`) governs terminology. Dates render with `Intl.DateTimeFormat` (Gregorian calendar by default,
configurable), numbers with the locale's digits configurable (Latin digits default for data tables).
