| File                                                                       | Generated by                                  | Contents                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sbom.cdx.json`                                                            | `node licenses/generate-sbom.mjs`             | CycloneDX 1.6 SBOM from `pnpm-lock.yaml`: every package with purl, SHA-512 integrity (from the lockfile), licence (from the installed package.json), scope, direct-dependency edges; the container images from `deploy/images.lock.json` |
| `inventory.csv`                                                            | same                                          | One row per package: `name,version,license,scope,direct_dependency_of,integrity,procurement,procurement_reason` (the last two since DG7, appended)                                                                                       |
| `THIRD-PARTY-NOTICES.md` (in the image at `/app/licenses/`, not committed) | `node licenses/collect-notices.mjs --out DIR` | Full LICENSE/NOTICE/COPYING/OFL texts of every **shipped** package (scopes `runtime` + `bundled`); packages that ship no licence file are listed explicitly                                                                              |

Scopes: `runtime` means the package is shipped as `node_modules` in the `mth-app` image (reachable from the
production dependencies of api, worker, config, db and shared, and of every workspace package they link in production,
such as `packages/reporting`; `linkedImporters` in `lib/lockfile.mjs`, the same closure `assemble-runtime.sh` ships). `bundled` means it is compiled into the web bundle
(reachable only from `apps/web` production dependencies; also present in the image's store). `development` means
build, lint and test tooling, never shipped.

The image build (`deploy/scripts/assemble-runtime.sh`) fails if the runtime tree contains any package outside the
`runtime`/`bundled` set of `inventory.csv`.

`--check` (run in CI's `images` job) fails when the committed files differ from a fresh generation, meaning the
lockfile changed without regenerating, or when a shipped package has no licence id.

## Procurement flag

`generate-sbom.mjs` classifies every package licence and every container image (ADR-0062 §7). The result is in the
`procurement` and `procurement_reason` columns of `inventory.csv`, and in the `mth:procurement` and
`mth:procurement-reason` properties of every SBOM component, containers included.

| `procurement`  | When                                                                                                                                                                                                                                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `not_required` | The SPDX expression is satisfied by the permissive set {MIT, MIT-0, ISC, Apache-2.0, BSD-2-Clause, BSD-3-Clause, 0BSD, BlueOak-1.0.0, CC0-1.0, Zlib}: a single id in the set, an `OR` with one satisfied operand, or an `AND` with every operand satisfied. Container images also accept `PostgreSQL` (the PostgreSQL License, OSI-approved and permissive). |
| `required`     | `UNLICENSED`, `SEE LICENSE IN …`, or any `LicenseRef-` id (a custom or commercial licence).                                                                                                                                                                                                                                                                  |
| `review`       | Anything else: `NOASSERTION`, copyleft (GPL, LGPL, AGPL, MPL, EPL, CDDL), OFL-1.1, CC-BY-\*, Python-2.0, an expression with a `WITH` exception, and an image whose licence note names several licences.                                                                                                                                                      |

This is an engineering classification of licence expressions. It is **not legal advice and not a procurement
decision**: Mobily procurement or legal decides what a `review` or `required` row needs.

`--check` also fails a direct dependency (every `dependencies`, `devDependencies` and `optionalDependencies` entry of
the root, `apps/*` and `packages/*` manifests, except `workspace:`) that is not an exact version, is not the version
the lockfile's importer resolved, or has no licence other than `NOASSERTION` in the inventory.
